# Sécurité

EVA tourne chez toi et a accès à des choses sensibles (fichiers, maison, papiers, ordinateurs pilotés). Les bonnes
pratiques sont dans [`MANUEL-INSTALLATION.md`](MANUEL-INSTALLATION.md) et [`NIS2.md`](NIS2.md) : compte
administrateur dès le premier lancement, double authentification, accès à distance par VPN uniquement (jamais de
redirection de port vers EVA), sauvegardes.

## Signaler une faille

N'ouvre pas de ticket public. Utilise **Security › Report a vulnerability** sur la page GitHub du dépôt (signalement
privé), avec la version concernée (`CHANGELOG.md`), les étapes pour reproduire et l'impact. Tu recevras une réponse
dès que possible ; la correction est publiée avant les détails.
